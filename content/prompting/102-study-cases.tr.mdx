### Örnek Çıktı

Yukarıdaki promptu kullanırken, örnek bir inceleme çıktısı:

**İncelenecek Kod:**
```python
def calculate_average(numbers):
    total = 0
    for n in numbers:
        total = total + n
    return total / len(numbers)
```

**İnceleme Çıktısı:**

> #### Kritik Sorunlar
>
> 1. **Sıfıra bölme**: `numbers` boşsa, `len(numbers)` 0 olur ve `ZeroDivisionError` oluşturur
> 2. **Tip işleme**: `numbers`'ın yinelenebilir olduğu veya sayısal değerler içerdiği doğrulanmıyor
>
> #### Stil ve En İyi Uygulamalar
>
> 1. Manuel döngü yerine yerleşik `sum()` fonksiyonunu kullanın
> 2. Tip ipuçları ve docstring eksik
> 3. `n` değişken adı açıklayıcı değil
>
> #### Performans
>
> 1. Mevcut: O(n) zaman, O(1) uzay - kabul edilebilir
> 2. Büyük veri setleriyle çalışıyorsanız generator kullanılabilir
>
> #### Güvenlik
>
> 1. Girdi doğrulama yok - beklenmeyen istisnalar oluşturabilir

#### Önerilen İyileştirmeler

```python
from typing import List, Union

def calculate_average(numbers: List[Union[int, float]]) -> float:
    """
    Bir sayı listesinin ortalamasını hesaplar.
    
    Args:
        numbers: Sayısal değerlerin listesi
        
    Returns:
        Sayıların ortalaması
        
    Raises:
        ValueError: Liste boşsa
        TypeError: Liste sayısal olmayan değerler içeriyorsa
    """
    if not numbers:
        raise ValueError("Boş listenin ortalaması hesaplanamaz")
    
    if not all(isinstance(n, (int, float)) for n in numbers):
        raise TypeError("Tüm öğeler sayısal olmalıdır")
    
    return sum(numbers) / len(numbers)
```

### Sonuçlar

Yapılandırılmış prompt şunları içeren kapsamlı kod incelemeleri üretir:

1. **Belirlenen uç durumlar**: Boş liste işleme, tip doğrulama
2. **Stil iyileştirmeleri**: `sum()` kullanımı, tip ipuçları, docstrings
3. **Performans optimizasyonları**: Algoritma verimliliği analizi
4. **Güvenlik değerlendirmeleri**: Girdi doğrulama ve hata yönetimi
5. **Yeniden düzenlenmiş kod örnekleri**: Açıklamalarla tam çözümler

## Prompt Mühendisliği En İyi Uygulamaları

### 1. Spesifik Olun

**Kötü:**
```text
Bu belgeyi özetleyin.
```

**İyi:**
```text
Ana kararlar, mali etkiler ve eylem maddelerine odaklanarak bu belgenin 200 kelimelik bir yönetici özetini oluşturun. Ana fikirler için madde işaretleri kullanın.
```

### 2. Örnekler Sağlayın

**Kötü:**
```text
Metinden tarihleri çıkarın.
```

**İyi:**
```text
Metinden tarihleri çıkarın ve YYYY-MM-DD formatında formatlayın.

Örnek:
Girdi: "Toplantı 15 Mart 2024'te"
Çıktı: "2024-03-15"

Metin: {text}
```

### 3. Yapılandırılmış Çıktı Kullanın

**Kötü:**
```text
Bu kodu inceleyin.
```

**İyi:**
```text
Bu kodu inceleyin ve bu formatta geri bildirim sağlayın:

## Hatalar
[Hataları listeleyin]

## Stil Sorunları
[Stil sorunlarını listeleyin]

## Öneriler
[Öneriler sağlayın]

Kod: {code}
```

### 4. Kısıtlamalar Belirleyin

**Kötü:**
```text
Bir özet yazın.
```

**İyi:**
```text
Şunları içeren bir özet yazın:
- Tam olarak 150 kelime
- Basit dil kullanın (8. sınıf seviyesi)
- En az 3 anahtar nokta dahil edin
- Bir sonuçla bitirin

Belge: {document}
```

### 5. Rol ve Bağlam Dahil Edin

**Kötü:**
```text
Bu metni çevirin.
```

**İyi:**
```text
Teknik dokümantasyon konusunda uzman profesyonel bir çevirmensiniz. Bu metni İngilizce'den İspanyolca'ya çevirin, teknik doğruluğu koruyarak ve kod örneklerini koruyarak.

Metin: {text}
```

## Yaygın Prompt Kalıpları

| Kalıp | Kullanım Durumu | Örnek |
|---------|----------|---------|
| Rol + Görev | Uzman analizi | "Kıdemli bir geliştiricisiniz. Bu kodu inceleyin..." |
| Few-Shot Öğrenme | Tutarlı format | Görevden önce 2-3 örnek sağlayın |
| Zincir Düşünce | Karmaşık akıl yürütme | "Adım adım düşünün: 1) ... 2) ..." |
| Çıktı Formatı | Yapılandırılmış veri | "Alanlarla JSON olarak çıktı: ..." |
| Kısıtlamalar | Kalite kontrolü | "Maksimum 200 kelime, basit dil kullanın" |
| Yinelemeli İyileştirme | Kalite iyileştirme | Üret → İncele → İyileştir |

## Anahtar Çıkarımlar

| Teknik | Kullanım Durumu | Fayda |
|-----------|----------|---------|
| Rol Atama | Kod İnceleme, Çeviri | Uzman seviyesi analiz |
| Yapılandırılmış Çıktı | Veri Çıkarma, Sınıflandırma | Tutarlı format |
| Kılavuzlar ve Kısıtlamalar | Özetleme, Üretim | Kalite kontrolü |
| Örnekler (Few-Shot) | Karmaşık görevler | Daha iyi doğruluk |
| Zincir Düşünce | Akıl yürütme görevleri | Şeffaf süreç |
| Prompt Zincirleme | Çok adımlı görevler | Daha iyi organizasyon |
| Yinelemeli İyileştirme | İçerik üretimi | Daha yüksek kalite |

## Pratik Alıştırmalar

1. **Test Durumu Üretimi**: Bir fonksiyon için kapsamlı test durumları üreten bir prompt oluşturun
2. **Kod Açıklama**: Kodu yeni başlayanlara açıklamak için bir prompt tasarlayın
3. **API Dokümantasyonu**: Koddan API dokümantasyonu üreten bir prompt oluşturun
4. **Toplantı Notları**: Toplantı transkriptlerini eylem maddelerine özetleyen bir prompt oluşturun
5. **Kod Yeniden Düzenleme**: Yeniden düzenleme iyileştirmeleri öneren bir prompt tasarlayın

## Özet

Etkili prompt mühendisliği gerektirir:

- **Netlik**: Ne istediğiniz konusunda spesifik olun
- **Yapı**: Net formatlama ve organizasyon kullanın
- **Bağlam**: İlgili arka plan bilgileri sağlayın
- **Örnekler**: İyi çıktının nasıl göründüğünü gösterin
- **Kısıtlamalar**: Kalite kontrolü için sınırlar belirleyin
- **Yineleme**: Sonuçlara göre promptları iyileştirin

Bu çalışma örnekleri, net talimatlar, bağlam, çıktı formatları ve örneklerle yapılandırılmış promptların önemli ölçüde daha iyi AI yanıtlarına nasıl yol açtığını gösterir. Anahtar, görevi AI'nın perspektifinden düşünmek ve istenen çıktıyı üretmek için gereken tüm bilgileri sağlamaktır.
