# Prompting'e Giriş

Prompting 101'e hoş geldiniz! Bu ders, AI dil modelleriyle etkili iletişim kurma sanatı olan prompt mühendisliğinin temellerini kapsar.

## Prompt Mühendisliği Nedir?

Prompt mühendisliği, AI dil modellerinden istenen çıktıları almak için metin girdilerini (promptları) tasarlama ve optimize etme pratiğidir. Büyük Dil Modelleri (LLM'ler) ile çalışan herkes için çok önemli bir beceridir.

<Mermaid chart={`
flowchart LR
    User[Kullanıcı Niyeti] --> Prompt[Prompt Tasarımı]
    Prompt --> LLM[Dil Modeli]
    LLM --> Output[Oluşturulan Yanıt]
    Output --> Eval[Değerlendirme]
    Eval -->|Yinele| Prompt
`} />

## Bir Prompt'un Temel Bileşenleri

### 1. Talimat

Talimat, modele hangi görevi gerçekleştireceğini söyler. Net ve spesifik olun.

<MultiLanguageCode
  python={`# İyi talimat
prompt = "Aşağıdaki makaleyi 3 madde halinde özetle:"

# Belirsiz talimat (bundan kaçının)
belirsiz_prompt = "Bu metinle bir şeyler yap:"`}
  turkish={`# İyi talimat
prompt = "Aşağıdaki makaleyi 3 madde halinde özetle:"

# Belirsiz talimat (bundan kaçının)
belirsiz_prompt = "Bu metinle bir şeyler yap:"`}
  typescript={`// İyi talimat
const prompt = "Aşağıdaki makaleyi 3 madde halinde özetle:";

// Belirsiz talimat (bundan kaçının)
const belirsizPrompt = "Bu metinle bir şeyler yap:";`}
  csharp={`// İyi talimat
var prompt = "Aşağıdaki makaleyi 3 madde halinde özetle:";

// Belirsiz talimat (bundan kaçının)
var belirsizPrompt = "Bu metinle bir şeyler yap:";`}
  dart={`// İyi talimat
final prompt = "Aşağıdaki makaleyi 3 madde halinde özetle:";

// Belirsiz talimat (bundan kaçının)
final belirsizPrompt = "Bu metinle bir şeyler yap:";`}
/>

### 2. Bağlam

Bağlam, modelin görevi daha iyi anlaması için gerekli bilgileri sağlar.

<MultiLanguageCode
  python={`# Bağlam ile
prompt = """
Sen bir müşteri hizmetleri temsilcisisin.
Müşteri: Ürünüm hala gelmedi.
Sen: [Yanıt ver]
"""

# Bağlam olmadan
prompt = "Ürünüm hala gelmedi."`}
  turkish={`# Bağlam ile
prompt = """
Sen bir müşteri hizmetleri temsilcisisin.
Müşteri: Ürünüm hala gelmedi.
Sen: [Yanıt ver]
"""

# Bağlam olmadan
prompt = "Ürünüm hala gelmedi."`}
  typescript={`// Bağlam ile
const prompt = \`
Sen bir müşteri hizmetleri temsilcisisin.
Müşteri: Ürünüm hala gelmedi.
Sen: [Yanıt ver]
\`;

// Bağlam olmadan
const prompt = "Ürünüm hala gelmedi.";`}
  csharp={`// Bağlam ile
var prompt = @"
Sen bir müşteri hizmetleri temsilcisisin.
Müşteri: Ürünüm hala gelmedi.
Sen: [Yanıt ver]
";

// Bağlam olmadan
var prompt = "Ürünüm hala gelmedi.";`}
  dart={`// Bağlam ile
final prompt = """
Sen bir müşteri hizmetleri temsilcisisin.
Müşteri: Ürünüm hala gelmedi.
Sen: [Yanıt ver]
""";

// Bağlam olmadan
final prompt = "Ürünüm hala gelmedi.";`}
/>

Modelden nasıl bir çıktı istediğinizi belirtin.

- Muz
- Portakal

- Muz
- Portakal

Format: {"ürünler": ["ürün1", "ürün2"]}
""";`}

## Özet

- **Talimat**: Net ve spesifik olun
- **Bağlam**: Modelin görevi anlaması için gerekli bilgileri sağlayın
- **Format**: İstediğiniz çıktı formatını belirtin
- **Örnekler**: Few-shot öğrenme kullanın
- **Adım Adım**: Karmaşık görevler için düşünme sürecini bölün
