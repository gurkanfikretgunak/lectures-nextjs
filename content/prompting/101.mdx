# Introduction to Prompting

Welcome to Prompting 101! This lecture covers the fundamentals of prompt engineering - the art of communicating effectively with AI language models.

## What is Prompt Engineering?

Prompt engineering is the practice of designing and optimizing text inputs (prompts) to get desired outputs from AI language models. It's a crucial skill for anyone working with Large Language Models (LLMs).

## Key Components of a Prompt

### 1. Instruction

The instruction tells the model what task to perform. Be clear and specific.

<MultiLanguageCode
  python={`# Good instruction
prompt = "Summarize the following article in 3 bullet points:"

# Vague instruction (avoid this)
vague_prompt = "Do something with this text:"`}
  turkish={`# İyi talimat
prompt = "Aşağıdaki makaleyi 3 madde halinde özetle:"

# Belirsiz talimat (bundan kaçının)
belirsiz_prompt = "Bu metinle bir şeyler yap:"`}
  typescript={`// Good instruction
const prompt = "Summarize the following article in 3 bullet points:";

// Vague instruction (avoid this)
const vaguePrompt = "Do something with this text:";`}
  csharp={`// Good instruction
var prompt = "Summarize the following article in 3 bullet points:";

// Vague instruction (avoid this)
var vaguePrompt = "Do something with this text:";`}
  dart={`// Good instruction
final prompt = "Summarize the following article in 3 bullet points:";

// Vague instruction (avoid this)
final vaguePrompt = "Do something with this text:";`}
/>

### 2. Context

Context provides background information that helps the model understand the task better.

<MultiLanguageCode
  python={`prompt = """
You are a technical writer specializing in software documentation.
Your audience is beginner developers.

Task: Explain what an API is in simple terms.
"""`}
  turkish={`prompt = """
Yazılım dokümantasyonu konusunda uzman bir teknik yazarsınız.
Hedef kitleniz yeni başlayan geliştiricilerdir.

Görev: API'nin ne olduğunu basit terimlerle açıklayın.
"""`}
  typescript={`const prompt = \`
You are a technical writer specializing in software documentation.
Your audience is beginner developers.

Task: Explain what an API is in simple terms.
\`;`}
  csharp={`var prompt = @"
You are a technical writer specializing in software documentation.
Your audience is beginner developers.

Task: Explain what an API is in simple terms.
";`}
  dart={`final prompt = """
You are a technical writer specializing in software documentation.
Your audience is beginner developers.

Task: Explain what an API is in simple terms.
""";`}
/>

### 3. Input Data

The actual content the model should process.

## Best Practices

1. **Be Specific**: Vague prompts lead to vague outputs
2. **Provide Context**: Help the model understand the situation
3. **Use Examples**: Show, don't just tell
4. **Iterate**: Refine your prompts based on outputs
5. **Test Variations**: Try different phrasings
