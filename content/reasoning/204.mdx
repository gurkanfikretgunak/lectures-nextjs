## Orchestration: VS Code Copilot Edits Mastery

Make atomic feature developments covering multiple files (Frontend + Backend + Database) with a single command (Cmd+I) using Copilot Edits.

Feature development covering the entire stack with a single prompt:

```markdown

```typescript

- Success handling

### 2. Backend API
```typescript
// routes/auth.ts

- Request validation
- Password hashing

- Error handling
```

### 3. Database
```sql

### 4. Tests
```typescript

All these changes are made atomically with a single prompt!

## Terminal Agents: Autonomous Error Resolution

Process autonomous error resolution workflows by transferring errors directly from terminal to editor.

    Analyze --> Fix[Automatic Fix]
    Fix --> Validate[Validation]

### TypeScript Error Handling

```markdown
# Scenario: TypeScript Compilation Errors

## Terminal Output

```
src/services/UserService.ts:45:12 - error TS2322: 
Type 'string' is not assignable to type 'number'.

45     user.id = userId;
            ~
```

## AI Agent Process

1. Error Parse: File, line, error type detected
2. Context Load: Related file and type definitions loaded
3. Analysis: Root cause analyzed
4. Fix: Automatic fix suggested
5. Apply: Applied to editor

## Prompt (Automatic)

"Fix TypeScript error in terminal:
- File: src/services/UserService.ts
- Line: 45
- Issue: Type mismatch (string → number)
- Solution: Convert userId to number or fix type definition"
```

1. Analyze test output

## Automatic Fix

```typescript

  // Validation

```

### Build Error Resolution

```markdown
# Scenario: Build Errors

## Terminal Output

```
Error: Cannot find module '@/components/Button'
   at src/pages/Home.tsx:12:25
```

## AI Agent Process

1. Check import path
2. Verify file existence
3. Check path alias
4. Create missing file or fix import

## Automatic Solution

```typescript

import { Button } from '@/components/Button'

// After: Fixed import
import { Button } from '@/components/ui/button'
// or
import { Button } from './components/Button'
```

## Terminal Agent Best Practices

### 1. Error Pattern Recognition

```markdown
# Error Patterns AI Will Recognize

1. TypeScript Errors
   - TS2322: Type mismatch
   - TS2307: Cannot find module
   - TS2345: Argument type error

2. Runtime Errors
   - ReferenceError: Variable not defined
   - TypeError: Cannot read property
   - SyntaxError: Unexpected token

3. Test Failures
   - Assertion errors
   - Timeout errors
   - Mock errors

4. Build Errors
   - Module resolution
   - Dependency errors
   - Configuration errors
```

### 2. Context-Aware Fixes

```markdown
# Context-Aware Error Resolution

Terminal Error → AI Analysis:
1. Detect error type
2. Load related files
3. Find root cause
4. Select best solution
5. Check side effects
6. Apply fix
```

### 3. Validation Loop

```markdown
# Automatic Validation Loop

Fix Applied → Validation:
1. Syntax check
2. Type check
3. Test run
4. Build check
5. Lint check

All checks pass → Success
One check fails → Retry with different approach
```
