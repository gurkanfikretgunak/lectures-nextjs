### Attention Mechanism

```python
# Simplified attention calculation
def attention(Q, K, V):
    """
    Q: Query matrix
    K: Key matrix
    V: Value matrix
    """
    # Scaled dot-product attention
    scores = (Q @ K.T) / sqrt(d_k)
    weights = softmax(scores)
    output = weights @ V
    return output
```

### Position Encoding

Since transformers process all tokens simultaneously, positional information must be added:

```python
# Sinusoidal position encoding
def positional_encoding(position, d_model):
    PE = np.zeros((position, d_model))
    for pos in range(position):
        for i in range(0, d_model, 2):
            PE[pos, i] = sin(pos / (10000 ** (i / d_model)))
            PE[pos, i+1] = cos(pos / (10000 ** (i / d_model)))
    return PE
```

### Decoder-Only (GPT-style)

- Autoregressive generation
- Causal attention (can only see past tokens)
- Examples: GPT-4, Claude, LLaMA

### Encoder-Only (BERT-style)

- Bidirectional context
- Good for classification/understanding
- Examples: BERT, RoBERTa

### Encoder-Decoder (T5-style)

- Full context for input
- Autoregressive output
- Examples: T5, BART

### LoRA (Low-Rank Adaptation)

```python
# Instead of updating full weight matrix W
# Update: W' = W + A @ B
# where A is (d × r) and B is (r × d), r << d

class LoRALayer:
    def __init__(self, in_dim, out_dim, rank=8):
        self.W = pretrained_weights  # Frozen
        self.A = nn.Linear(in_dim, rank)
        self.B = nn.Linear(rank, out_dim)
    
    def forward(self, x):
        return self.W(x) + self.B(self.A(x))
```

### Quantization

Reduce model size and speed up inference:

| Precision | Bits | Size Reduction |
|-----------|------|----------------|
| FP32 | 32 | 1x |
| FP16 | 16 | 2x |
| INT8 | 8 | 4x |
| INT4 | 4 | 8x |

```python
# Pseudo-code for quantization
def quantize_int8(weights):
    scale = weights.max() / 127
    quantized = (weights / scale).round().clamp(-128, 127)
    return quantized, scale
```
