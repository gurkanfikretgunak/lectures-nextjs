### Dikkat Mekanizması

```python
# Basitleştirilmiş dikkat hesaplama
def attention(Q, K, V):
    """
    Q: Sorgu matrisi
    K: Anahtar matrisi
    V: Değer matrisi
    """
    # Ölçekli nokta çarpım dikkati
    scores = (Q @ K.T) / sqrt(d_k)
    weights = softmax(scores)
    output = weights @ V
    return output
```

### Konum Kodlama

Transformer'lar tüm tokenları aynı anda işlediği için konumsal bilgi eklenmelidir:

```python
# Sinüzoidal konum kodlama
def positional_encoding(position, d_model):
    PE = np.zeros((position, d_model))
    for pos in range(position):
        for i in range(0, d_model, 2):
            PE[pos, i] = sin(pos / (10000 ** (i / d_model)))
            PE[pos, i+1] = cos(pos / (10000 ** (i / d_model)))
    return PE
```

### Sadece Decoder (GPT tarzı)

- Otoregresif üretim
- Nedensel dikkat (sadece geçmiş tokenları görebilir)
- Örnekler: GPT-4, Claude, LLaMA

### Sadece Encoder (BERT tarzı)

- İki yönlü bağlam
- Sınıflandırma/anlama için iyi
- Örnekler: BERT, RoBERTa

### Encoder-Decoder (T5 tarzı)

- Girdi için tam bağlam
- Otoregresif çıktı
- Örnekler: T5, BART

### Chinchilla Optimal

Eğitim tokenları ≈ 20 × Parametreler

```
7B model → 140B token
70B model → 1.4T token
```

### LoRA (Düşük Rank Adaptasyonu)

```python
# Tam ağırlık matrisi W'yi güncellemek yerine
# Güncelle: W' = W + A @ B
# burada A (d × r) ve B (r × d), r << d

class LoRALayer:
    def __init__(self, in_dim, out_dim, rank=8):
        self.W = pretrained_weights  # Dondurulmuş
        self.A = nn.Linear(in_dim, rank)
        self.B = nn.Linear(rank, out_dim)
    
    def forward(self, x):
        return self.W(x) + self.B(self.A(x))
```

### Kuantizasyon

Model boyutunu azaltın ve çıkarımı hızlandırın:

| Hassasiyet | Bit | Boyut Azaltma |
|-----------|------|----------------|
| FP32 | 32 | 1x |
| FP16 | 16 | 2x |
| INT8 | 8 | 4x |
| INT4 | 4 | 8x |

```python
# Kuantizasyon için sahte kod
def quantize_int8(weights):
    scale = weights.max() / 127
    quantized = (weights / scale).round().clamp(-128, 127)
    return quantized, scale
```
